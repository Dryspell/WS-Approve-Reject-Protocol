### Rules Refinements - In Progress

- [x] **Remove Exhaust Mechanic**
  - [x] Laborers no longer become "exhausted" from lack of food
  - [x] Food is just another tradeable resource
  - [x] Simplifies Production phase

- [x] **Merge Market + Negotiation Phases**
  - [x] Single "Action Phase" handles production + trading simultaneously
  - [x] Sticky notes enable private negotiations during production
  - [x] Reduces total phase count to 3 (Action, Voting, Combat)
  - [x] Time allocation: 5-10 minutes

- [x] **Add Side-Bets for Eliminated Players**
  - [x] Players without votes can bet on round outcomes
  - [x] Separate side-pot for spectator bets
  - [x] Keeps eliminated players engaged
  - [x] Re-entry option: 15 Marbles = 1 new laborer

- [x] **Simplify Combat to Clockwise Attack**
  - [x] No battle arena or complex positioning
  - [x] Majority laborers attack player to your left
  - [x] Compare Attack vs Defense totals
  - [x] Simultaneous resolution

- [x] **Remove Era System**
  - [x] Play continuous rounds until win condition
  - [x] No artificial 3x3 era structure
  - [x] Game length: ~log₂(total laborers) rounds

- [x] **Simplify Buildings**
  - [x] 4 basic resource locations always available
  - [x] Optional upgrade buildings (skip for first playtests)
  - [x] No multi-round construction

- [ ] **Balance Testing: Starting Laborers**
  - [ ] Test with 5 laborers (base, ~5 rounds)
  - [ ] Test with 8 laborers (extended, ~6 rounds)
  - [ ] Test with 10 laborers (long, ~7 rounds)
  - [ ] Document ideal count for game feel

- [ ] **Balance Testing: Starting Resources**
  - [ ] Test with 5 resources (player choice)
  - [ ] Test with 8 resources
  - [ ] Consider fixed vs choice distribution
