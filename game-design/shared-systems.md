## Currency Systems

### Empty Marbles (MT)

- Primary and pass-through currency
- Used for all market transactions
- Fixed exchange rates to real-world currency
- Unlimited resource with controlled distribution

### Essence Marbles (MBLS)

- Special magic glass balls
- Store Essence generated from Battle Arena sacrifices
- Used to maintain Time Shards
- Valuable resource with limited supply

## Market Systems

### Resource Markets

- All resource trading must occur through The Vote Exchange
- Markets are tied to specific Vote Exchange instances
- Markets close when their associated Vote Exchange instance terminates
- Resources must be destroyed or relocated when markets close

### Trading Periods

- Defined time frames for trading and voting
- Varies by server type
- Affects market dynamics and resource management
- Determines server tick rates

## Multi-TimeFrame System

### Server Hierarchy

- Tiered tree structure based on trading period lengths
- Parent-child relationships between servers
- Resource and vote transfer between servers
- Different gameplay pacing for different server types

### Server Types

- City (1-month trading period)
- Expedition (1-minute trading period)
- Other time frames as needed

### Resource Transfer

- Moving down the tree: Join new games
- Moving up the tree: Return to parent server
- Resource preservation rules
- Vote voiding for upward transfers

## Game Termination Rules

### Parent-Child Relationships

- Children games require parent game
- Parent termination forces child termination
- Child games cannot outlast parent
- Predictable parent end times
- Round completion before termination

### The Eternal Format

- Ultimate parent server
- Super-majority voting trigger
- No vote avoidance
- 50/50 pot distribution
- Transaction fee contributions
- Vall Street order management
