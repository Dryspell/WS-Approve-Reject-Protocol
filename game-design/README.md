# The Vote Exchange Documentation

## Overview

The Vote Exchange is a complex game system that combines market-based voting mechanics with MMO/colony-building features. This documentation is organized into several key documents that cover different aspects of the game.

## Core Documents

- [rules.md](./rules.md) - Core Vote Exchange mechanics and gameplay
- [rules-colony-builder.md](./rules-colony-builder.md) - MMO/colony-building extension
- [shared-systems.md](./shared-systems.md) - Shared systems between core and colony builder

## Supporting Documents

- [mathematical-analysis.md](./mathematical-analysis.md) - Mathematical analysis of game mechanics
- [monetization.md](./monetization.md) - Monetization strategies and SaaS details
- [legal-considerations.md](./legal-considerations.md) - Legal aspects and considerations
